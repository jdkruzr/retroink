# ChicagoFLF

ChicagoFLF by Robin Casady. Font Library identifies this adaptation as public
domain: https://fontlibrary.org/en/font/chicagoflf (retrieved 2026-09-14).

Source: https://fontlibrary.org/assets/fonts/chicagoflf/a2e4a3d14e40fa7076a0a1bc06f3de43/d7982e4c4d683e1fe63fdefd5100f1e3/ChicagoFLFRegular.ttf

Chicago's original design is credited to Susan Kare. This project uses the
ChicagoFLF adaptation and does not extract fonts from macOS. The TTF is only a
build input; generated 1-bit glyph data is stored in firmware flash.

Regenerate: `.venv/bin/python scripts/generate_system6_font.py` (Pillow and
fonttools required). UI strings outside its coverage use the existing UI font.
