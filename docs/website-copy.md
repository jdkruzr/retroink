# RetroInk website copy

## Short description

RetroInk is a free, open-source e-reader firmware by AltFlow that gives the
Xteink X3 and X4 a classic black-and-white desktop interface. It is built on
CrossInk and CrossPoint Reader and released under the MIT License.

## Project description

RetroInk combines CrossInk's capable EPUB reader, library tools, dictionaries,
wireless transfers, reading statistics, and synchronization with a dedicated
System 6-inspired interface. Windows, menus, buttons, dialogs, icons, boot and
sleep screens are designed for a crisp one-bit e-ink display without adding a
second framebuffer or large theme images.

RetroInk is an independent AltFlow project. It is built on CrossInk, which is
based on CrossPoint Reader. It is not affiliated with or endorsed by Apple,
Xteink, CrossInk, or the CrossPoint Reader project.

## Suggested download note

RetroInk is experimental community firmware. Download the X3/X4 firmware and
SHA-256 checksum from the latest GitHub release. Source code, the MIT License,
upstream attribution, installation instructions, and recovery instructions are
available in the GitHub repository.

Suggested source and release URL: `https://github.com/smashedllama/RetroInk`
